# Satriko's Room

A portfolio site presented as a cozy 3D room: visitors explore Satriko's desk, shelves and gadgets, and each object opens a part of his work and story.

Docs: see `docs/design/README.md`

## Commands

- `yarn dev` / `yarn build` / `yarn test` / `yarn lint` / `yarn typecheck`
- Node 24 via `nvm use` (Node >= 22.22 required), yarn
